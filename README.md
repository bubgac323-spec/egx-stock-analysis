# منصة تحليل أسهم البورصة المصرية (EGX)

منصة ويب عربية مفتوحة (بدون تسجيل أو كلمات سر) لتحليل أسهم البورصة المصرية باستخدام **Next.js (App Router)** و**TypeScript** و**PostgreSQL (Drizzle ORM)** و**Tailwind CSS**، مع تكامل **Mansa API** على الخطة المجانية.

> **تنويه دائم:** المحتوى تحليل ومعلومات فقط، وليس نصيحة استثمارية ولا توصية بالشراء أو البيع. القرار والمسؤولية على المستخدم.

---

## المزايا والأدوات (11 أداة بثلاثة مستويات: مبتدئ / متوسط / خبير)
1. **لوحة السوق وقائمة المتابعة (`/`):** بحث، فرز، تصفية بالقطاع، متابعة محلية (`localStorage`)، وإظهار تأخير البيانات (30 دقيقة) ووقت آخر تحديث.
2. **صفحة السهم التفصيلية (`/stocks/[ticker]`):** شموع 30 دقيقة مخزنة وجدول خام مع تصدير CSV لوضع الخبير.
3. **المؤشرات الفنية:** SMA، EMA، RSI، MACD، بولينجر، نسبة الحجم، والتذبذب التاريخي مع شروح عربية وصفية.
4. **مرشِّح الأسهم (`/screener`):** قوالب جاهزة للمبتدئ وشروط حرة للمتوسط والخبير.
5. **مقارنة الأسهم (`/compare`):** مقارنة حتى 4 أسهم جنباً إلى جنب.
6. **الاختبار التاريخي (`/backtest`):** اختبار قواعد متعددة مع حقول عمولة ورسوم فارغة افتراضياً، تقسيم داخل/خارج العينة، وتحذير العينة الصغيرة (< 30 صفقة).
7. **التنبيهات المحلية (`/alerts`):** محفوظة في `localStorage` وتعمل فقط والموقع مفتوح.
8. **الملخص اليومي للسوق:** أكبر المرتفعين والمنخفضين والأعلى حجماً وحالة السوق العامة.
9. **متتبع المحفظة (`/portfolio`):** محلي في المتصفح مع تصدير/استيراد JSON.
10. **القاموس ودليل المبتدئين (`/glossary`).**
11. **أداة الترتيب التاريخي الشفاف (`/ranking` و `/ranking/methodology`):** أوزان قابلة للتعديل مع إحصاءات تاريخية إلزامية بجانب كل سهم.

## التشغيل محلياً

1. انسخ ملف البيئة:
   ```bash
   cp .env.example .env
   ```
2. املأ المتغيرات في `.env`:
   - `DATABASE_URL`: رابط PostgreSQL (محلي أو Neon أو Vercel Postgres).
   - `MANSA_API_KEY`: مفتاح Mansa API (لا يُوضع أبداً في كود المتصفح).
   - `ADMIN_KEY`: مفتاح سري لحماية صفحة `/admin` ونقطة المزامنة اليدوية.
   - `CRON_SECRET`: مفتاح Cron الخاص بـ Vercel.
3. ثبّت الحزم وادفع مخطط قاعدة البيانات:
   ```bash
   npm install
   npm run db:push
   ```
4. شغّل الاختبارات وبناء الإنتاج:
   ```bash
   npm test
   npm run typecheck
   npm run build
   npm run dev
   ```

## النشر على Vercel وإعداد Cron
1. اربط المستودع بـ Vercel وأضف متغيرات البيئة (`DATABASE_URL`, `MANSA_API_KEY`, `ADMIN_KEY`, `CRON_SECRET`).
2. ملف `vercel.json` يضبط مهمة Cron تلقائية على `/api/cron/sync` كل 30 دقيقة خلال ساعات تداول البورصة المصرية (الأحد–الخميس)، بما يحترم حدود الخطة المجانية لـ Mansa API (**100 طلب/يوم و1500 طلب/شهر**).
3. جميع نقاط الـ API العامة محمية بمحدد معدل طلبات (Rate Limiting).
