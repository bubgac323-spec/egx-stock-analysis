# منصة تحليل أسهم البورصة المصرية (EGX)

منصة ويب عربية مفتوحة (بدون تسجيل أو كلمات سر) لتحليل أسهم البورصة المصرية باستخدام **Next.js (App Router)** و**TypeScript** و**PostgreSQL (Drizzle ORM)** و**Tailwind CSS**، مع تكامل **Mansa API** على الخطة المجانية و**Yahoo Finance** للسجل التاريخي اليومي.

> **تنويه دائم:** المحتوى تحليل ومعلومات فقط، وليس نصيحة استثمارية ولا توصية بالشراء أو البيع. القرار والمسؤولية على المستخدم.

---

## المزايا والأدوات (11 أداة بثلاثة مستويات: مبتدئ / متوسط / خبير)
1. **لوحة السوق وقائمة المتابعة (`/`):** بحث بالاسم العربي أو الإنجليزي أو الرمز، فرز، تصفية بالقطاع، متابعة محلية (`localStorage`)، وإظهار تأخير البيانات (30 دقيقة) ووقت آخر تحديث.
2. **صفحة السهم التفصيلية (`/stocks/[ticker]`):** ملخص بكلمات بسيطة، سجل الأيام اليومي الكامل مقسّماً بالصفحات، وجدول خام مع تصدير CSV لوضع الخبير.
3. **المؤشرات الفنية:** SMA، EMA، RSI، MACD، بولينجر، نسبة الحجم، والتذبذب التاريخي مع شروح عربية وصفية.
4. **مرشِّح الأسهم (`/screener`):** قوالب جاهزة تملأ المعايير فعلياً وشروط حرة للمتوسط والخبير.
5. **مقارنة الأسهم (`/compare`):** مقارنة شاملة لـ 2–4 أسهم من كل الأسهم مع رسم مطبّع إلى 100 وحفظ الاختيار في الرابط.
6. **الاختبار التاريخي (`/backtest`):** اختبار قواعد متعددة مع حقول عمولة ورسوم فارغة افتراضياً، تقسيم داخل/خارج العينة، وتحذير العينة الصغيرة (< 30 صفقة).
7. **التنبيهات المحلية (`/alerts`):** محفوظة في `localStorage` وتعمل فقط والموقع مفتوح.
8. **الملخص اليومي للسوق:** أكبر المرتفعين والمنخفضين والأكثر تداولاً وحالة السوق العامة.
9. **متتبع المحفظة (`/portfolio`):** محلي في المتصفح مرتبط تلقائياً بآخر سعر مخزّن مع تصدير/استيراد JSON.
10. **القاموس ودليل المبتدئين (`/glossary`):** أكثر من 20 مصطلحاً مع أمثلة رقمية وبحث فوري.
11. **أداة الترتيب التاريخي الشفاف (`/ranking` و `/ranking/methodology`):** أربعة أوزان قابلة للتعديل (المجموع 100) مع إحصاءات تاريخية إلزامية بجانب كل سهم.

## التشغيل محلياً

1. انسخ ملف البيئة:
   ```bash
   cp .env.example .env
   ```
2. املأ المتغيرات في `.env`:
   - `DATABASE_URL`: رابط PostgreSQL (محلي أو Neon أو Vercel Postgres).
   - `MANSA_API_KEY`: مفتاح Mansa API (لا يُوضع أبداً في كود المتصفح).
   - `ADMIN_KEY`: مفتاح سري لحماية صفحة `/admin` ونقطة المزامنة اليدوية.
   - `CRON_SECRET`: مفتاح Cron الخاص بـ Vercel.
3. ثبّت الحزم وادفع مخطط قاعدة البيانات:
   ```bash
   npm install
   npm run db:push
   ```
4. شغّل الاختبارات وبناء الإنتاج:
   ```bash
   npm test
   npm run typecheck
   npm run build
   npm run dev
   ```

---

## النشر على Vercel وإعداد Cron
1. اربط المستودع بـ Vercel وأضف متغيرات البيئة (`DATABASE_URL`, `MANSA_API_KEY`, `ADMIN_KEY`, `CRON_SECRET`).
2. ملف `vercel.json` يضبط مهمة Cron يومية واحدة على `/api/cron/sync` (`0 13 * * 0-4` — متوافقة مع خطة Vercel Hobby)، وتستهلك طلباً واحداً فقط يومياً من حصة Mansa API المجانية (**100 طلب/يوم و1500 طلب/شهر**).
3. جميع نقاط الـ API العامة محمية بمحدد معدل طلبات (Rate Limiting).

---

## استرجاع السجل التاريخي الكامل (Yahoo Finance)
1. الصق أوامر SQL لجدول `backfill_progress` في محرر SQL داخل Neon.
2. افتح صفحة `/admin` وأدخل مفتاح `ADMIN_KEY`.
3. اضغط على **"ابدأ / أكمل الاسترجاع"** واترك الصفحة مفتوحة حتى يكتمل الشريط (يمكنك الإيقاف المؤقت والاستئناف في أي وقت لأن التقدم محفوظ في قاعدة البيانات).
